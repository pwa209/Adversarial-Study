# Adversarial Study

Research code, figures and aggregate statistical results for a computational study of observation and mechanistic inference in a released consciousness-model framework.

The dated research release is in [release/science_advances_20261024](release/science_advances_20261024/README.txt). It contains five main figures and seven supplementary figures as **PDF, SVG and 400 dpi PNG**, their R source, 37 pinned aggregate source files, complete statistical CSV exports and the completed cross-mechanistic analysis modules. The full study pipeline is in [study_pipeline](study_pipeline/README.md).

The manuscript is kept local and is **not included in this repository**.

## Results and scope

The release distinguishes parameter recovery, finite pulse-response prediction, internal pathway balance and human report prediction. It retains all tested contrasts, null results, fixed sensitivities, matching failures and actual denominators. Configuration-bootstrap stability is distinct from human-participant uncertainty. No independent human mechanism or randomized intervention is claimed.

The behavioural target is **42 people, split 26 training, eight validation and eight test**. Both actual human-data fine-tunings and the separate clinical adaptation remain prerequisites for cross-system comparison. This target is separate from the EEG samples: 183 eligible spatial-analysis episodes from 31 people, six spatial test people, and the earlier five-person/32-episode forecasting test set.

## Reproduction

The dated release includes a self-contained R figure workflow and CSV export script. See its README and [statistical data dictionary](release/science_advances_20261024/statistics/README.txt). Figures can be reproduced from aggregate data without accessing raw EEG or model weights. Full native analyses additionally require the identified original assets and runtimes.

Source recordings, third-party model checkpoints, raw simulation arrays, local authentication/deployment state and manuscript files are not bundled. Original source identities, licenses and data-access conditions remain documented in the dated release.
